# GiftLink — User Stories

**Repository:** [https://github.com/nasrinioo/fullstack-capstone-project](https://github.com/nasrinioo/fullstack-capstone-project)


---

## Authentication & profile

1. As a **new visitor**, I want to **register with email and password** so that **I can post and manage my giveaways securely**.

2. As a **returning user**, I want to **log in and receive a JWT** so that **the app can remember my session for protected actions**.

3. As a **logged-in user**, I want to **update my profile (username / email)** so that **my public identity stays accurate**.

## Browsing & discovery

4. As a **community member**, I want to **see a list of available gifts on the home page** so that **I can quickly scan what people are giving away**.

5. As a **browser**, I want to **open an item’s detail view** so that **I can read the full description before requesting or commenting**.

6. As a **browser**, I want to **search or filter gifts by category** so that **I can find items relevant to my needs (e.g. Kitchen, Furniture)**.

## Giving & engagement

7. As a **donor**, I want to **publish household items I no longer need** so that **someone nearby can reuse them instead of buying new**.

8. As a **recipient**, I want to **leave comments on an item** so that **I can coordinate pickup or ask questions** (when comments API/UI are enabled).

## Platform quality

9. As a **stakeholder**, I want **automated build, test, and deploy stages in CI/CD** so that **each change is verified before release**.

10. As a **developer**, I want **Dockerized services** so that **MongoDB, API, and frontend run consistently on any machine**.
